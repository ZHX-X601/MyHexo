一、变量与动态类型

1.1 变量与字面量

  • 字面量：程序中直接书写的固定值，如 10、8.5、"Python"、True、None。
  • 变量：存储单个数据的容器，定义格式 变量名 = 值，如 num = 1114.1。
  • 动态类型：Python 是动态类型语言，变量不需要声明类型，类型由当前存的值决定，可以反复赋不同类型的值。这是与 C++/Java 静态类型最大的差异。

1.3 类型判断：type() 与 isinstance()

  • type(数据)：返回数据的确切类型（用于调试查看）。
  • isinstance(数据, 类型)：判断数据是否属于某类型，返回布尔，子类也算（面向对象中猫属于动物）。

写判断逻辑优先用 isinstance，它支持一次判断多个类型（传元组）：

两个容易踩的点：

  • bool 是 int 的子类：isinstance(True, int) 结果为 True。想严格区分布尔，要先 isinstance(x, bool) 或直接用 type(x) == bool。
  • 判断 None 不要用 isinstance(x, None)（None 不是类型，会报错），标准写法是 x is None；如果非要用 isinstance，写 isinstance(x, type(None))。判断”非 None 且有内容”用 if x is not None。

2.3 f-string 进阶格式（组合顺序）

格式说明符完整顺序：对齐 + 宽度 + 千分位 + 精度 + 类型。

位置 写法 示例
对齐 >右、<左、^居中（必须和宽度成对） >10
宽度 数字 10
千分位 逗号 ,
精度 .数字 .2
类型 f 浮点 / d 十进制整数 / % 百分比 / x 十六进制等 f

类型说明符区分：

  • f 是浮点，可以用精度（:.2f 控制小数位）。
  • d 是十进制整数，不能用精度（f"{255:.2d}" 会报错），补位用零填充 f"{255:05d}" → 00255，千分位 f"{1234567:,d}" → 1,234,567。
  • % 也是类型位，排在最后，会自动把值乘 100 再加百分号：f"{0.2567:.1%}" → 25.7%，不要自己再乘一次。

4.5 赋值、比较与逻辑运算符

  • 赋值：= += -= *= /= %= //= **=。
  • 比较：== != > >= < <=，返回布尔。
  • 逻辑：and（与）、or（或）、not（非），对应 C++/Java 的 &&、||、!，是单词不是符号。

判断”在 10-20 之间”：10 <= num <= 20 或 num >= 10 and num <= 20。

五、易踩坑与补充知识点

5.1 round() 是银行家舍入，不是四舍五入

round(x) 取整、round(x, n) 保留 n 位小数，但规则是四舍六入五成双：小数部分正好 .5 时看前一位，偶数舍、奇数进（向偶数靠拢）。

f"{2.5:.0f}" 输出也是 2，和 round() 同一套五成双规则，不是真四舍五入。需要四舍五入时：正数用 int(x + 0.5)，精确场景用 Decimal 的 ROUND_HALF_UP。

5.2 Decimal：精确十进制，金额计算用它

decimal 模块提供的精确十进制数，解决 float 二进制误差。构造时传字符串，不要传 float（会把误差一起带进来）。
