学习方式：对照黑马 Python+AI 讲义第 2 章第 2 节（流程控制语句）边看边敲，代码验证文件 02.py。已有 C++/Java 基础，重点记录 Python 与它们的写法差异。

一、if 条件判断

1.1 if…else 基本用法

条件不需要括号（C++/Java 需要 if (a >= 18)），代码块靠缩进区分，没有大括号，也没有分号。

1.2 if…elif…else 多分支

Python 没有 else if，多分支用 elif。执行顺序从上到下，满足第一个分支就不再往下判断，else 放最后兜底。

1.3 语法要点与坑

  • 缩进是语法不是风格：同一代码块缩进必须一致，混用 Tab 和空格直接报错。
  • 条件不用加括号，组合条件用 and/or（不是 &&/||）。
  • 多分支顺序很重要：成绩等级这类要先写高分条件再写低分，顺序反了会提前命中。
  • 换行续写用 \：

二、match 模式匹配（Python 3.10+）

针对同一个变量的多个固定值分支，比 if-elif 简洁。case 值1 | 值2 表示或，case _ 是默认兜底：

选择原则：

  • 固定值分支（星期、运算符、指令）→ match...case；
  • 范围判断、组合条件（score >= 85）→ if...elif。

三、while 循环

3.1 基本用法与 while…else

  • while 靠条件控制是否继续，条件结果必须是布尔。
  • 可带 else：循环正常结束（条件变 False）时执行；被 break 跳出则不执行。
  • 必须规划终止条件，否则死循环卡死。
